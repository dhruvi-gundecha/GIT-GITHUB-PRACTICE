## git and github note's :-

- git is like version control system.
- github is online directory/website.
- it saves changes and which person changes in which directory at when.

## =>commands :-

1. git --version => gives a version of git.

2. git init => initalize an empty git repository.

3. ls => gives a list of directory/folder.

4. ls -a => gives a list of hidden files.

5. mkdir name => make a new folder of name.

6. cd name_of_folder => goes inside the folder also add the path.

7. ls .git => gives a list of git

8. touch file_name => makes a new file.

9. git status => tracks a changes of files.

10. vim file_name => make a command line into working pad.

11. git add./add file_name => use for staging files.

12. rm file/directory name-rf => delete a directory/file /folder.

13. git commit -m "your msg write here" => commiting the files.

14. cat file name => gives whats inside this file.

15. git restore --staged file name => now in git status don't show anything it go on unstaged files now.

16. cd .. => use this to go back on one folder.

17. git reset #id => now you have unstaged above #id commits.
